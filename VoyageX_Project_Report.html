1. Executive Summary

VoyageX is a modern, enterprise-grade travel and hospitality platform engineered to deliver an integrated travel booking journey encompassing flight discovery, dynamic seat map selection, luxury stays reservation, VIP holiday packages, automated cancellations, and real-time traveler reviews.

The platform is built on an enterprise Java 25 (LTS) backend powered by Spring Boot 4.x and Spring Data JPA with an embedded H2 Database. The frontend features a lightweight, high-performance, glassmorphic interface built using modern HTML5, Vanilla CSS3, and ES6+ JavaScript. For cloud reliability, the project is packaged into a production-ready multi-stage Docker container with automated Continuous Integration & Continuous Deployment (CI/CD) hosted on Render.

Live Deployment URL: https://voyagex-travelbooking.onrender.com
GitHub Source Code: https://github.com/HarshithaR-cyber/voyagex-travelbooking

2. Detailed Task Completion Breakdown

The following matrix documents all modules, security workflows, and architectural enhancements engineered throughout the project lifecycle:

Task 1: Mandatory Authentication Gateway & Auth Guard COMPLETED
Engineered a complete security gating system ensuring visitors must authenticate before entering the VoyageX main portal.
  • Initial Screen Gating: Root route (/) automatically directs unauthenticated visitors to login.html before homepage access.
  • Modern Travel-Themed UI: Designed a responsive, glassmorphic authentication interface consistent with VoyageX branding.
  • Tabbed Authentication Workflow: Seamless switching between Sign In, Create Account, and Forgot Password forms.
  • Client & Server Validation: Real-time email syntax regex, password strength checks, and feedback alerts.
  • SessionTokenService: Cryptographically secure session token generation and server-side validation (/api/auth/verify-session).
  • Dynamic Navbar Integration: Navbar displays authenticated traveler's name, avatar, and active status.
  • Server-Side Logout: Immediate session revocation on sign-out, clearing client state and returning users to login.
Task 2: Flight Search, Dynamic Pricing & Availability Engine COMPLETED
Comprehensive flight booking search supporting dynamic origin/destination queries, cabin class tiers, and fare calculation.
  • Multi-Criteria Search: Origin, destination airport lookup, departure & return dates, passenger counter.
  • Cabin Class Multipliers: Economy, Premium Economy, Business, and First Class fare structures.
  • Dynamic Pricing Service: Live price adjustment algorithms calculating taxes, fees, and real-time flight demand.
  • Price Freeze Feature: Locks quoted flight prices for 48 hours for a small holding fee.
Task 3: Interactive Aircraft Cabin Seat Selection COMPLETED
Interactive 2D aircraft seating layout enabling passengers to visually choose their preferred seats.
  • Visual Seat Grid: Real-time visualization of window, middle, and aisle seats.
  • Live State Indicators: Clear distinction between available, selected, occupied, and extra-legroom seats.
  • Booking Integration: Selected seat numbers are attached to the passenger's confirmed reservation PNR.
Task 4: Live Flight Status & Tracking Tracker COMPLETED
Real-time status inquiry for scheduled flights across global departure and arrival gates.
  • Flight Number Query: Real-time lookup for commercial flight numbers (e.g., VX-101, VX-204).

Hotel discovery and room booking system with personalized filters and amenities.

Premium all-inclusive vacation bundles offering flight + hotel packages with exclusive member savings.

3. System Architecture & REST API Specifications

VoyageX is structured using Spring Boot's clean Controller-Service-Repository layered architecture:

Method Endpoint Module Description
POST /api/auth/login Authentication Validates credentials & returns session token
POST /api/auth/register Authentication Registers traveler account with validation
GET /api/auth/verify-session Authentication Validates active session token
POST /api/auth/logout Authentication Revokes session token server-side
POST /api/auth/forgot-password Authentication Handles password reset requests
POST /api/flights/search Flights Searches available flights by criteria
GET /api/flights/status/{flightNo} Flights Retrieves live flight tracking information
POST /api/bookings/flight Bookings Confirms passenger reservation with seat
GET /api/hotels/recommendations Hotels Fetches lodging recommendations by city
POST /api/hotels/book Hotels Reserves room with confirmation code
GET /api/vip-deals VIP Packages Fetches curated travel packages
POST /api/cancellations/quote Cancellations Calculates instant refund quote
